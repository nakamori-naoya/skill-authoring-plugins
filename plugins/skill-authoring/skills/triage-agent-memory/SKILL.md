# triage-agent-memory

読み終えたagentは、agentの記憶と案件の規約を一件ずつ振り分け、利用者がどれをpluginへ戻し、どれを残し、どれを消すかを決められる資料を作れる。

## 本質

記憶と案件の規約は、作業のたびに少しずつ足され、見直されないまま残る。古いものは、新しいセッションで、今の規約と逆の指示として働く。繰り返し現れた判断は、案件の中に閉じたままだと、次の案件でまた一から学び直すことになる。この仕事は、その二つを見つけて、持ち主へ返す。

振り分けは提案である。記憶も案件の規約もpluginも、それぞれ持ち主がいる。このskillは、どれも書き換えず、何をどこへ移すかを根拠と一緒に示すところまでを行う。

## 入力

棚卸しする記憶のdirectoryの絶対path（索引と本文のfileがある場所）と、対象の案件のrepositoryの絶対pathを受け取る。案件の規約は、そのrepositoryのAGENTS.md、CLAUDE.md、その配下の規約のfileから読む。昇格先を探すために、pluginのworkspaceの絶対pathも受け取る。各plugin repositoryのREADMEの「このpackageが持つ判断」の節を読んで、どの判断をどのpluginが持つかを確かめる。資料の保存先は、新しく作るMarkdownの絶対pathで受け取る。

## 判断基準

### 一件の単位

記憶は、本文のfile一つを一件とする。索引の一行と本文が食い違っていれば、それ自体を一つの所見として記録する（索引は、新しいセッションで最初に読まれるので、本文と逆のことを言っていると、本文より強く効く）。案件の規約は、一つの判断を述べる段落か項目を一件とする。

### 昇格か、留めるか、破棄か

一件ごとに、[振り分けの基準](references/triage-criteria.md)の六つの問いに答えてから振り分ける。

昇格を提案するのは、その判断を案件の固有の値を抜いた一文の原則にでき、別の題材に当てても害が無く、技術上の理由か外部の契約に根拠があるときである。昇格先は、その判断を持つpluginの入口として名前で示す。持ち主がまだいなければ、「持ち主が決まっていない」と書き、どのpluginに置くのが自然かを仮説として添える。

案件に留めるのは、根拠が利用者の好みや、その案件だけの技術の選択にあるときである。

破棄を提案するのは、今の案件の規約、コード、pluginのどれかと食い違って古くなったとき、または同じ判断をpluginがすでに持っていて重複しているときである。どれと食い違うかを、fileと行で示す。

一件の中で、原則の部分は昇格、値の部分は案件に留める、のように分かれることがある。そのときは分けて書く。

### 分からないとき

この資料の結論は、記憶と規約の一件ごとの振り分けの提案であり、どれを採るかは読み手が決める。ある一件の振り分けが一つに決まらなくても、その一件を候補付きの未決として載せれば、ほかの件の提案は変わらない。だから止まらず、最も筋の良い振り分けを仮説として置き、仮説であることと、採らなかった振り分け、それを確かめる方法を、資料の未決の節に書いて進む。記憶の本文が何を指しているか読み取れないときも同じ扱いにする。記憶や規約は他人が持つ資料なので、直して食い違いを解くことはしない。

## 手順

1. 記憶の索引と本文、案件の規約、各plugin repositoryのREADMEの「このpackageが持つ判断」を読む。
2. 一件ずつ、六つの問いに答え、昇格、留める、破棄のどれかに振り分ける。索引と本文の食い違い、規約とコードの食い違いも所見として記録する。
3. 資料を書く。先頭に振り分けの件数と、利用者がまず決めるべきこと（昇格の提案の中で影響の大きいもの、今の規約と逆を言っている記憶）を書く。続けて、振り分けごとに一件ずつ、根拠と提案先を書く。最後に未決を書く。文の書き方は、`write-doc` が公開の資料として宣言している「書くときの規範」（公開入口 `write-doc` の `references/writing-norms.md`）に従う。
4. 受け取った保存先へ保存し、読み戻して、全件が振り分けられていることを確かめる。

## 停止条件

止まるのは、記憶のdirectoryか案件のrepositoryが読めないとき、保存先が絶対pathで与えられていないか書き込めないときである。止まるときは、読めた範囲と、要る入力を返す。

## 出力

保存した資料の絶対pathと、振り分けの件数（昇格、留める、破棄）、今の規約と逆を言っている記憶の一覧、未決の件数を報告する。記憶と規約とpluginは変更していないことも報告する。
