# 記憶と規約の振り分けの資料に共通する条件

この条件は、実行の担当が triage-agent-memory で作った振り分けの資料（以下、資料）と、実行の担当の最後の報告（以下、報告）を判定するためのもので、どの案件にも当てる。案件に固有の条件は、この後ろに続く。条件は判断の型だけを書き、正しい振り分けは書かない。各条件の「重み」は点数にまとめるときの値で、判定の厳しさは変えない。重み3は利用者の原則の芯（持ち主の資料を変えない、案件の値を規律にしない、推測で埋めずに仮説と明示する、食い違いを持ち主へ返す）、重み2は資料の骨組み、重み1は細部である。資料が存在しない、または空のときは、それを読む条件はすべて FAIL とする。

実行の担当は、記憶のディレクトリ（`work/out/memory/`）、案件の repository（`work/out/project/`）、plugin の workspace（`work/out/plugins-ws/`）を渡された。渡す前の元の写しは `materials/memory/`、`materials/project/`、`materials/plugins-ws/` にある（案件の repository の git の履歴は、元の写しには無く、`materials/project-history.md` に書いてある。資料が履歴に触れていたら、そのファイルと突き合わせる。`work/out/project/.git` は比べない）。

## 持ち主の資料を変えない

### triage-owners-untouched

重み: 3

PASS：`work/out/memory/`、`work/out/project/`（`.git` を除く）、`work/out/plugins-ws/` の各ファイルが、`materials/` の元の写しと同じ内容で、足されたファイルも消えたファイルも無い。

FAIL：一つでも内容が変わった、足された、消えたファイルがある。FAIL にするときは、そのファイルを挙げる。

## 振り分けの骨組み

### triage-every-item

重み: 2

根拠の欄に、記憶の本文のファイルごとと、案件の規約の判断ごと（`materials/project/` の AGENTS.md の段落と docs の下のファイル）に、資料での振り分けを一覧にしてから判定する。

PASS：記憶の本文のファイルのすべてと、案件の規約の判断のすべてが、昇格、留める、破棄、未決のどれかに振り分けられている。一件の中で原則と値を分けて振り分けたものは、振り分けたものとして数える。

FAIL：振り分けられていない記憶か規約の判断が一つでもある。

### triage-reasons-and-targets

重み: 2

PASS：昇格の提案には、昇格先の plugin の入口の名前か「持ち主が決まっていない」と置き先の仮説が、破棄の提案には、食い違う相手か重複する持ち主のファイルが、それぞれ書かれている。何を指すか読み取れないために仮説として未決に置いた件は、この条件ではなく、仮説の置き方を見る条件で判定し、ここでは数えない。昇格先として挙げた plugin が、その判断を持つと README に書いている。

FAIL：昇格先の無い昇格、根拠の相手の無い破棄がある。または、README がその判断を持つと書いていない plugin を昇格先にしている。

### triage-lead-decisions

重み: 1

PASS：資料の先頭に、振り分けの件数と、利用者がまず決めるべきこと（影響の大きい昇格の提案、今の規約と逆を言っている記憶）が書かれている。

FAIL：先頭に件数か、まず決めるべきことが無い。

### triage-prose

重み: 1

PASS：資料が見出しと地の文で構造を作り、一件ごとの振り分けの理由を文章で書いている。表を使うなら、件の比較に限られ、理由はセルでなく文章にある。

FAIL：振り分けの理由の大半が表のセルか箇条書きの断片で、文章が無い。
