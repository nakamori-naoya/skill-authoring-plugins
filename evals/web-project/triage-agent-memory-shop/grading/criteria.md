# 通販サイトの案件の振り分けに固有の条件

この案件の記憶と規約には、次のものを意図して入れてある。外部の契約に根拠のある判断と一つの案件の値が一件に混ざったもの、今の規約と逆を言う記憶、索引の一行が本文と逆を言う記憶、plugin が既に持つ判断と重なるもの、利用者の好み、読み取れない記憶、持ち主のまだいない判断である。

### shop-values-not-promoted

重み: 3

PASS：資料が、plugin へ昇格させる提案の文に、この案件だけの値（再試行の回数3回や間隔の上限2秒、Stripe という製品名、フラグを消すまでの2週間、pnpm や Next.js）を規律として含めていない。再試行の記憶のように原則と値が一件に混ざったものは、原則を昇格、値を案件に留める、のように分けている。

FAIL：案件の値が昇格の提案の規律として書かれている。または、原則と値の混ざった記憶を、分けずに丸ごと昇格か丸ごと留めるにしている。

### shop-stale-memory

重み: 3

PASS：yarn で入れるという記憶を、案件の AGENTS.md（pnpm へ移った）と食い違う古いものとして破棄の提案にし、食い違う相手のファイルを示している。どちらが新しいかの根拠（規約の文面か、git の履歴の日付）が書かれている。

FAIL：yarn の記憶を昇格か留めるにしている。または、破棄にしても食い違う相手か、新しさの根拠が無い。

### shop-index-mismatch

重み: 2

PASS：日時の保存について、索引の一行（UTC で保存）と本文（日本時間で保存）が逆を言っていることを、所見として記録している。

FAIL：索引と本文の食い違いに触れていない。

### shop-unreadable-as-hypothesis

重み: 3

PASS：「例の件は B 案で」という記憶を、何を指すか読み取れないものとして、止まらずに、最も筋の良い振り分けの仮説、採らなかった振り分け、確かめる方法とともに未決に置いている。記憶の中身を推測で補って事実のように書いていない。

FAIL：この記憶のせいで資料を作らずに止まった。または、何を指すかを推測で決めて、仮説と示さずに振り分けた。または、未決に置いても仮説か確かめる方法が無い。

### shop-duplicate-and-preference

重み: 2

PASS：表駆動のテストの記憶（と案件の docs のテストの決まり）を、testing-conventions が既に持つ判断との重複として破棄の提案にしている。絵文字を使わない記憶を、利用者の好みとして案件に留め、別の案件でも言われていることから利用者全体の指示へ移す提案を添えている。

FAIL：表駆動のテストを昇格の提案にしている。または、絵文字の記憶を昇格の提案にしている。または、どちらかに触れていない。
